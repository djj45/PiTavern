# 0.7.0 长局上下文契约

## 权威与范围

完整 JSONL 是审计、候选切换、编辑、重生成、导入导出与恢复的日志。模型工作集是确定性的派生数据；构建或预览不写聊天、不执行工具、不结算回合。0.7.0 不改变存档与回合提交语义，不实现秘密/角色知识投影或双阶段生成。

事实优先级：当前世界快照决定金额、库存、位置、角色状态和时钟；世界事件只解释变化；剧情摘要与用户发言只提供历史叙事线索或意图，不得覆盖硬状态。任何过时数字均按带来源的历史摘录解释，不作为另一个账本。

## 输入、输出与预算

纯构建器接收当前活动路径装配后的消息、可选的窗口外历史、当前世界快照与预算。输出发送消息、结构化摘录、取舍说明、保留/压缩范围及来源。来源包含消息序号、轮次、内容 SHA-256、原文区间与类别；用户意图、助手叙事、已有 summary 和工具回执分开标记。摘录为原文，不补写未发生事实；规则提取不是语义理解或完整记忆保证。

系统指令、当前权威状态、当前轮完整工具链和配置保留的最近轮次为不可拆分区域。完整旧工具调用/结果可转换为带调用名、ID、成功/错误状态与来源的回执，不重放参数或执行工具。跨系统注入、未闭合/孤立工具链保持原样；不能为了缩短上下文制造孤立调用/结果。

从旧剧情全文而非前 300 字提取承诺、发现、线索与事件；在预算内按查询相关性、事实类型、时间选择。每条摘录有固定长度上限，预算不足明确记录被省略事实数量；不会承诺任意大小存档在任意预算内完整保存。摘要是辅助历史，完整细节仍可按路径召回。

预算顺序：输出预留和 10% 安全余量 → 固定设定/世界书/硬状态 → 最近轮次和当前工具链 → 历史线索。tokenizer 的正文 token、接口封装估算、字符量和供应商实际用量分别标注；不可拆分区域超预算时阻止模型请求并说明原因。没有静默截断当前用户消息的后备方案。

## 分支与缓存

只接收活动路径的消息，不能遍历 `_pitavernReplies` 或隐藏 continuation 来取事实。缓存只是可丢弃的进程内加速索引，不是存档；按来源内容、聊天作用域和摘要算法版本寻址，输出选取每次按当前预算重算。来源 revision 纳入索引键，切分支、编辑、重生成、迁移、恢复后不复用旧索引；缺失、损坏或重启后重建。候选中相同正文也不能借缓存混入其他路线。

## 固定评测与交付

M1：冻结 0.6.0 压缩器；固定 100/500/1000 轮及超长工具结果，记录字符量、构建耗时、关键事实命中。深层分支由 M3 存储集成夹具验证，M1 固定其验收规则：沿深度路径逐项切换，只能包含选中路线事实。

M2：纯函数构建器及工具链/原文来源/预算验证。M3：分支、缓存、编辑、重生成、迁移、恢复与重建。M4：simple/bridge/takeover 与活动诊断，显示保留范围、压缩范围、事实来源、遗漏和计数单位。M5：固定购买、移动、承诺、线索、反转场景与恢复/导入导出；Node 22/24、完整浏览器、重新打包和 verify:release。

每步独立提交并运行对应回归；固定样本比较同一预算下的字符量、构建耗时和事实命中率，不用“更短”代替事实正确性。真实模型表现另列，未调用供应商不计为通过。

参考：fate-sandbox ADR 0008（Separate the Session Log from the Settlement Working Set） 的完整日志与工作集分离原则；不引入其双阶段结算语义。

M1 实测基线（字符预算 16000，保留最近 3 轮；本机 Node 26，仅合成样本）：

| 回合 | 原始字符量 | 0.6 工作集字符量 | 末尾事实命中 | 单次构建 ms |
| --- | ---: | ---: | ---: | ---: |
| 100 | 87770 | 34779 | 0/3 | 0.65 |
| 500 | 438570 | 169179 | 0/3 | 2.21 |
| 1000 | 877071 | 337181 | 0/3 | 5.10 |

旧算法压缩后仍超过预算，长工具结果尾部线索也遗漏。性能数字受硬件与计数器影响，后续比较保留同一冻结实现，不能把该毫秒数当 CI 稳定阈值。固定深层样本为 12 层未选 continuation，使用真实分支选择器逐层进入进行隔离复验。

M5 同机对照（Node 26，字符预算 16000、保留 3 轮；未预热的单次纯构建，不含网络，非性能承诺）：

| 回合 | 旧工作集字符 | 新工作集字符 | 末尾事实命中（旧→新） | 旧/新构建 ms |
| --- | ---: | ---: | --- | ---: |
| 100 | 34779 | 15829 | 0/3 → 3/3 | 0.97 / 5.60 |
| 500 | 169179 | 15942 | 0/3 → 3/3 | 2.16 / 14.23 |
| 1000 | 337181 | 15808 | 0/3 → 3/3 | 4.01 / 27.05 |

工作集输入长度分别减少约 54%、91%、95%；提取和来源追踪增加构建耗时。事实命中仅度量三个固定目标是否进入模型输入，不代表真实模型回答正确率。计数器、工具声明和设定变化会改变可用空间；实际 token 预算另有 tokenizer 与估算计数用例。

`npm run verify:context` 共 28 组检查：基线 1、构建器 9、生命周期 6、模式 6、合成游戏 6。报告和逐次本地模型请求保存在 `data/test-runs/context-*`。游戏用真实会话/事务路径执行本地 SSE 合成供应商，三种模式分别使用 100/500/1000 回合；余额 100→83，重生成仍为 83；备份恢复并再次迁移后价格 23、余额 60、库存 2；导入和新建服务对象后可继续生成。真实供应商未调用。

提取边界：每个来源文本部分最多取 8 个候选区间（无规则命中时保留首尾片段），每条最长 240 字，预算内最多选择 128 条。`omittedFacts` 计数已提取但未选入的候选，不包含未被规则识别的语义。固定/当前工具区域超过预算时拒绝请求，不用裁切来伪造成功。
