# 0.12.0 候选与升级

## 0.12.0 游戏内容候选

0.11.0 已发布；0.12.0 当前停在开发验收候选，未打标签或发布公共 Release。

本版交付 [《雾港最后一盏灯》](../games/fogharbor/README.md) 及独立准备命令；现有资料库不会自动安装游戏，也不会迁移旧聊天。卡片与书为内容版本 1.1.0，模板继续使用 v4/rulesVersion=1。恢复旧程序前保留当前配置和资料备份。

发行源码必须包含 `games/fogharbor/` 三份 JSON 及玩家/作者手册。运行 `npm run verify:game` 验证标准导入、开局、真实工具流程与分支恢复；完整 CI 为29套，浏览器为73项。真实供应商不属于离线验收，不能把合成通关计为模型自主可玩性通过。

体验修正版范围见 [FOGHARBOR_EXPERIENCE.md](FOGHARBOR_EXPERIENCE.md)：交互可用性由服务端计算，只公开作者主动授权的前置关系；案件证据来自当前已知事实；“备齐修灯材料”不代替灯塔验证；分支显示回合/候选、摘要与原始时间，失败通过诊断和重试处理。旧聊天不会自动更新到内容1.1.0/模板版本2，复验用新独立资料库。M4固定行动耗时尚未启用，仍仅明确等待推进。真实模型两条结局及调用成本需单独复验，不能用合成输入检查宣称已修复模型叙事表现。

以下是此前候选的验收记录，保留其当时边界。


本候选聚焦 NPC 每日日程与世界时间推进。0.10.0 正式发布提交 `066b10eb285824ac480e1072cb10ab5660660573` 冻结；0.11 从该提交的独立分支按 M1–M7 交付。独立复验前不打标签或正式发布。规则见 [WORLD_SCHEDULES.md](WORLD_SCHEDULES.md)，固定预期和专项入口见 [SCHEDULE_ACCEPTANCE.md](SCHEDULE_ACCEPTANCE.md)。

只有明确执行 `advance_time` 才按 `(旧时间,新时间]` 逐个消费日程点，按绝对分钟及日程 ID 排序。NPC 移动后，任务交付、购买和知识交互立即检查新位置。日程不接取任务、不发奖励或传播知识；正文失败、停止和提交冲突撤销整轮变化，只重写正文不推进世界。

## 升级与回退

安装 0.11.0 不会自动升级 v1–v3 世界、修改旧哈希或批量重写聊天。没有日程的旧世界继续使用原时间推进语义。

1. 停止生成，整库备份并确认 `stDataDir`；保留原版本和原资料。
2. 使用待复验候选提交和锁文件，执行 `npm ci` 和 `./start.command`。
3. 模板编辑器显式“启用日程规则（v4）”，为 NPC 添加稳定 ID、每日到达时间及地点。每 NPC 一份、每份最多16点、世界最多64份，不允许给玩家配置日程。同一日程的时间不能重复。
4. 用作者模拟预览确认到达顺序和跨天效果；模拟以初始位置为起点，从指定累计分钟启用，不写聊天或草稿。初始位置由原初始状态决定，不根据过去或当刻的日程重摆角色。
5. 保存并发布模板，新聊天使用新版本。已有聊天从“作者视图（含秘密）→ 更新模板”预览全部恢复点，确认后备份并原子迁移。各候选、检查点、原生swipe及隐藏后续分别从自己的当前分钟启用新日程，不补跑过去，不改变已有金额、库存、知识或任务进度。
6. 已有日程的修改、删除或改 ID（含绑定角色、时间、地点或备注）首版阻断；需要不同规则建立新世界。既有任务和事实的保守迁移限制继续生效。任一坏恢复点阻断整份迁移；叙事包保留原来源，不匹配时禁用重写。

单次最多处理256个触发点（死亡、停用和已在目的地的跳过也计入），超限整次拒绝，可缩短等待。死亡或inactive不会被复活，恢复alive只处理未来点。时钟上限525600000分钟，数学日序从0计算，玩家继续显示“第1天”起。

v4 不能降级。回退到0.10.x前停止服务，保留当前资料，再恢复升级/迁移前的独立备份，按旧锁文件安装和构建；不要手工删字段强制回退。v4 手工修正不能直接改变时钟或日程进度，其他合法修正沿用现有入口。

真实供应商及真实模型人工验收为`not_requested`；尚未评测等待赴约、NPC不在场时的拒绝叙述、多事件叙述和真实可玩性。合成测试只验证输入、服务端执行和状态恢复，不宣称叙事质量提升。

## 信息与恢复边界

- 玩家默认HTTP/WS、查询工具、三种上下文模式、叙事包和诊断只接收玩家投影：当前公开状态及已发生的可见移动。完整时间表、未来目的地、内部日程ID、进度和作者备注仅在独立作者入口或完整存档中出现。
- 不扩展战争迷雾或NPC隐身。现有公开位置仍公开；NPC私人知识只用于服务端规则。普通角色卡、世界书及正文中的秘密不自动识别，也不清洗历史正文。
- 一次命令或一轮中NPC离开再返回、任务开放→关闭→开放时，累计中间视角变化。混合活动和缺来源证明的旧记录保守隐藏敏感内容，即使最终指纹相同；保留真实用量、状态和原始记录。
- 恢复至v3/v2/v1、无世界或未知分支后，历史v4内容仍按当前有效授权过滤，不因旧版本缺日程而跳过知识/任务过滤。重启、查询和恢复不执行日程，不依赖最多100条的近期事件重放。
- JSONL、模板导出和备份含完整秘密、任务及日程；MD仅活动路径正文。本地作者系统不是多人访问控制，也不是分享脱敏存档格式。
