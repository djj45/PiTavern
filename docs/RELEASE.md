# 0.7.0 发布与升级

0.7.0 聚焦长局上下文与分支记忆一致性。完整 JSONL 继续作为日志，模型工作集按当前活动路径、权威世界状态、历史和预算确定性构建。金额、库存、位置由当前世界快照决定；事件只解释变化；历史摘录保留叙事线索，不结算或改写世界。契约与评测见 [CONTEXT_CONTRACT.md](CONTEXT_CONTRACT.md)。

发布流程：确认最终提交的 Node 22/24 CI，通过后从该提交重新生成源码包并执行 `verify:release`；公共标签与 GitHub Release 使用同一提交和包，不复用旧候选包。

## 升级与回退

0.6.x → 0.7.0 不迁移聊天格式，不批量改写聊天正文、世界模板、候选或检查点。

1. 停止生成，整库备份并确认 `stDataDir`。
2. 切换到 0.7.0 提交，按锁文件安装并执行 `./start.command`。
3. 原有压缩开关、最近保留轮次和模型预算配置继续生效；simple、bridge、takeover 均使用新工作集。接管模式窗口外历史也参与线索选择。
4. 打开“统计 → 生成记录与上下文诊断 → 长局记忆诊断”，查看保留/压缩范围、来源、预算和省略情况。旧生成记录没有这些字段时仍可读取。
5. 事实缓存仅在进程内，重启后按来源重建；切换分支、编辑、重生成、迁移或恢复后不会沿用另一份来源索引。预览构建不改聊天文件。

回退时停止服务，切回升级前提交并按锁文件安装，再重新构建。旧版本忽略新增诊断字段；需要回退游戏进度时，从独立备份恢复，保留当前资料。0.6.0 的模板迁移、备份和只读保护继续适用。

## 边界

- 摘录是带来源的规则提取，不保证所有自然语言线索都被识别；每个来源片段最多保留 8 条候选，每条最多 240 字，预算内最多选择 128 条。界面显示候选省略数量；未识别的事实不包含在该数量内。
- 固定设定、当前世界、最近轮次与当前工具链不能被静默裁切；它们超过预算时阻止请求，需要调整预算或设定。
- 未引入公开/秘密/角色知识投影、双阶段生成、只重写正文、任务或 NPC 自动目标。0.8/0.9 依实际游戏验收调整。
- 第三方复杂预设、真实大库与真实供应商表现仍须另行验收；本地合成供应商不代表真实模型的推理质量。
