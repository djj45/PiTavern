# 0.10 线性任务契约（M1 冻结）

0.9 正式发布提交 `aff72aafd02b8b91237c0bc0d17df6d431570df9` 保持冻结；任务在独立分支交付 M1–M7，独立复验前不打标签、不正式发布。真实供应商与真实可玩性人工验收默认 `not_requested`。

## 版本与数据

世界 schema v3 新增任务；v1/v2 严格读取、哈希和执行行为保持，读取不升级。v3 沿用 v2 知识规则，新增模板 `quests`（最多64项）、初始 `actorMoney`（最多256项，仅非玩家角色）和快照 `questStates`（最多64项）。已有初始玩家金额仍由 `initial.money` 决定。

任务定义：稳定 `id`、公开后可见 `name`、仅作者可见 `description`、`openConditions`、1–8项 `stages`、`reward`。阶段有稳定 `id`、`objective`、`conditions`；仅最后阶段可有 `delivery: {toActorId,itemId,quantity}`。奖励为 `{fromActorId,money,items:[{itemId,quantity}]}`，实际从指定非玩家 NPC 支付，必须与玩家同地、alive。交付 NPC 同样须在场可交互。物品不凭空生成，金额和库存遵守既有上限；不允许先收取交付物再把它充当原本不足的奖励库存。

条件复用位置、NPC在场、玩家持有物品、指定角色已知事实，全部 AND；每组最多16项。名称100字，作者备注2000字，阶段目标1000字，奖励最多16种物品。引用必须有效，任务/阶段/奖励物品/初始金额角色不得重复，NPC不能为玩家。无随机、分叉、期限、循环、离线推进或自主目标。

快照仅记录已接取任务：`{questId,status:active|completed,acceptedTurn,completedStages:[{stageId,turn}],completedTurn?}`。完成阶段必须是定义的连续前缀；active 不能包含全部阶段；completed 必须恰好包含全部阶段及完成回合。非法/悬空/损坏进度不能执行或靠迁移修复。

## 执行与原子性

`world_quest({questId,action:accept|advance})` 只接受这两个字段，玩家身份取模板绑定。服务端检查开放条件后接取；每次推进只检查并完成当前一个阶段，已完成阶段不重新检查或倒退。当前事务内同任务同动作的重复请求返回原收据，最多推进一个阶段；不同任务/accept 后 advance 可顺序执行。跨事务再次 advance 才检查下一阶段，已完成任务返回 unchanged。

最终阶段重新检查当前阶段条件、交付双方位置/状态、玩家物品、奖励 NPC 在场和实际余额/库存、所有接收方上限。全部通过才在独立副本中同时交付、支付、记完成与事件；任何拒绝逐项不变。任务奖励每分支至多一次，不依赖易丢失的近期事件去重。事件携带 questId/stageId 和服务端生成的回执摘要。

所有变化加入 WorldTransaction，单阶段/双阶段均和整轮一起提交。正文失败、停止、空输出、预算或文件 revision 冲突撤销全部暂存效果。重启不继续未完成结算。正文重写沿用原数据包，不执行工具，全部状态不变；重新生成从回合前检查点重新结算。请求 ID 重放遵守0.9回执契约，包括坏行原文保留。

## 玩家边界与只读

查询、提示构建、面板、重启、迁移不执行接取/推进/领奖。玩家任务 DTO 只含已开放或已接取任务的 id/name/status、当前阶段目标和已完成阶段；不含作者备注、内部条件、未到阶段或奖励规则。未开放且未接取的任务连名称、ID、占位都不返回。角色预览的任务仅对绑定玩家角色可见；NPC私人知识仅用于服务端条件判断。作者对可见目标文本负责编排，不自动识别普通正文中的秘密，不做历史字符串清洗。

默认HTTP/WS、world_query/world_quest、三模式提示、叙事包和诊断统一使用玩家投影。事件只显示当前授权任务的服务端摘要；其他事件不能夹带任务引用。`questKey` 绑定视角和当前任务投影，独立加入上下文/缓存/活动过滤；v3缺少来源标识的活动保守隐藏。恢复v2/v1/无世界或未开放分支后，旧任务活动参数、摘要及阶段提示也隐藏，保留用量/状态/原活动文件。JSONL、备份及独立作者入口仍含完整资料；MD仅活动路径正文。

## 迁移与恢复

只允许显式 v1/v2→v3 升级；禁止任何降级。升级从空 questStates 开始，已有余额/库存/知识保持；v1知识从空关系开始。新增任务仅加入定义，不自动接取、推进或奖励。修改已有任务任意定义、删除或改 ID 首版阻断；需要新规则创建新任务 ID。初始NPC金额只影响新聊天，迁移不补钱。

全部活动世界、候选、检查点、原生swipe、隐藏continuation沿用原始源表校验及全聊天单次原子写入。任一坏恢复点阻断整体迁移，不给出部分结果。旧叙事包保留原始来源；迁移后不匹配禁用重写，不能补造任务来源。
