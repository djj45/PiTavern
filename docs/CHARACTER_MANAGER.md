# 角色卡管理页（0.5.x 开发）

状态：开发中，未发布。目标是把散落在侧栏导入、资料库世界书/正则编辑中的角色卡操作集中到一个管理页，同时保持现有聊天、群聊、世界书和导入归档兼容。

## 1. 范围

管理页提供：

- 列出 `characters/` 下所有角色卡：头像、名称、格式、描述摘要、标签、卡内世界书条目数、世界引用、聊天数。
- 查看/编辑常用角色卡字段：描述、性格、场景、默认开场白、备用开场白、示例对话、作者备注、系统提示、历史后指令、标签。
- 保留 PNG 图像、V2/V3 `chara`/`ccv3` 两个数据块、未知字段和卡片扩展；JSON 卡保留原顶层结构。
- 从管理页导入 PNG / JSON / CharX / BYAF（复用现有导入接口）。
- 导出原格式文件（PNG 下载图片，JSON 下载 JSON）。
- 复制为一张新卡（新名称、不会复制聊天）。
- 删除角色卡文件；不删除聊天、群聊或世界书。已有聊天变成“找不到角色卡”，必须明确警告。

不提供：

- 重命名已有角色卡。角色名同时是聊天目录/群聊成员/模板关联的 key，首版保持不可变。
- 完整卡面编辑器、头像替换、卡内世界书/正则编辑；这些继续在「资料 → 世界书/正则」。
- 删除角色卡时级联删除聊天。

## 2. 字段与格式

编辑字段使用现有归一化卡的往来映射：

| UI 字段 | V2/V3 字段 |
| --- | --- |
| 描述 | `description` |
| 性格 | `personality` |
| 场景 | `scenario` |
| 默认开场白 | `first_mes` |
| 备用开场白 | `alternate_greetings` |
| 示例对话 | `mes_example` |
| 作者备注 | `creator_notes` |
| 系统提示 | `system_prompt` |
| 历史后指令 | `post_history_instructions` |
| 标签 | `tags` |

- 名称、头像、`character_book`、`extensions`、`world` 引用不由本页修改。
- 字符串字段允许空串；备用开场白/标签为字符串数组，分别最多 100 条，单条最多 100000 字符。
- 保存后新聊天使用新开场白/系统提示；已有聊天正文、开场白记录和历史前缀不变。
- 导入 CharX/BYAF 继续走现有导入器，转为 JSON 卡或保留头像资源；管理页只刷新列表。

## 3. 存储、冲突和备份

- 卡片路径固定为 `<stDataDir>/characters/<文件名>`；管理页不移动文件、不改变文件名。
- 读/写使用文件字节 SHA-256 作为 revision；保存必须带 revision，冲突返回 409，不覆盖其他窗口修改。
- 保存前把原文件备份到 `<stDataDir>/.pitavern/card-backups/<路径哈希>/<时间戳>-<随机>.<扩展名>`。
- PNG 使用现有 `rewritePngCard` 只改卡 JSON，不改像素和其他 chunk；JSON 保持顶层 `spec`/`data` 或扁平结构。
- 写操作要求服务空闲；成功后广播资料变更；失败不留下临时文件或半张卡。
- 导出返回当前卡文件原字节；导出不触发写操作。

## 4. API

- `GET /api/character-cards`：摘要数组。
- `GET /api/character-cards/:name`：完整编辑 DTO + revision。
- `PUT /api/character-cards/:name`：`{ revision, fields }`；409 冲突。
- `POST /api/character-cards/:name/duplicate`：`{ name? }`；默认 `原名 副本`，自动避开重名。
- `DELETE /api/character-cards/:name`：只删角色卡文件；返回受影响聊天数警告。
- `GET /api/character-cards/:name/export`：原格式附件。
- 导入沿用 `POST /api/import/character`。

名称在 URL 中使用 `encodeURIComponent`；同名复制/文件名冲突返回 409。

## 5. UI

- 入口：侧栏「角色」标题旁「管理」，或顶栏「资料」；现有「＋导入」保留。
- 全屏对话框：左侧卡列表/搜索，右侧编辑表单；移动端单列、内部滚动。
- 保存按钮显示未保存状态；冲突时提示并重新载入；删除和复制二次确认。
- 卡内世界书/正则显示入口提示，不在本页直接编辑。
- 导入成功后刷新列表；保留原侧栏导入路径。

## 6. 验收

- 编辑描述/开场白/备用开场白/标签 → 保存 → 重启后仍保留；PNG 像素和未知字段不变。
- 两个窗口同时编辑：后保存者 409，不覆盖。
- 复制卡生成新名称和独立文件，不复制聊天；删除副本不影响原卡。
- 删除卡不删除聊天；重新导入同卡后旧聊天可继续读取（角色名相同）。
- 导入 CharX/BYAF 后列表出现新卡；导出 PNG/JSON 字节与当前文件一致。
- 390px 移动端可操作且无水平溢出。
- 已有聊天开场白、群聊成员、卡内世界书/正则和世界模板行为不回归。
