# 0.10 任务合成验收与独立复验入口

任务分支基于冻结的 0.9.0 发布提交，M1–M7 各自提交。候选仍需独立复验，不提前打标签或发布；完整本地证据保存在 `data/test-runs/`，源码候选与清单保存在 `data/releases/`。

`npm run verify:quests` 包含 65 组检查，使用独立 JSONL 库、动态端口和本地模拟 Chat Completions，不访问真实供应商：

| 脚本 | 组数 | 覆盖 |
| --- | ---: | --- |
| quest-schema-verify | 6 | v3 严格容量/引用、非法进度、玩家/NPC 投影、v1/v2 哈希与读取不变 |
| quest-rules-verify | 11 | 伪造拒绝、接取、真实购买与知识、阶段保留、交付奖励原子性、资金/库存不足、容量、幂等和撤销 |
| quest-game-verify | 28 | simple/bridge/takeover × 单/双阶段真实请求、失败/停止/空白回滚、重复调用/重启重放、三次重写、重生成检查点 |
| quest-lifecycle-verify | 10 | 同知识不同任务状态的分支隔离、隐藏后续、导入重启、全聊天迁移、坏恢复点、v2/v1/无世界 HTTP/WS/跨页活动过滤 |
| quest-boundaries-verify | 10 | 独立任务缓存、审计来源、三模式 1000 回合、正文超预算、提交冲突、v3 及运行中回退后的错误过滤 |

固定酒馆闭环断言：100 金币接取，购买长剑降到 83，真实知识交互后推进调查，最终交剑并从掌柜实际余额支付 30，玩家 113/剑0、掌柜87/剑10。重复请求或重启仍113；三次正文重写逐项保持世界/知识/变量/事件/结算标识；重生成最终回合从83/持剑/未完成重新结算到113。资金不足、正文失败、停止、空输出、超预算或提交冲突不会留下部分交付或奖励。

过滤验收截取完整供应商请求，包括工具结果和后续请求；检查未开放任务 ID、名称、内部条件、奖励配置和备注不出现，正文请求没有工具声明或原始状态。历史活动的任务指纹独立于知识指纹；恢复旧视角后保留状态和实际用量，隐藏旧参数/摘要/阶段提示，原始活动文件保持。v3 非活动分支的预览、搜索及命名备注在切换前隐藏；不修改存档正文。

Chromium 新增两项真实界面流程：作者从 v2 显式启用 v3、NPC 资金、条件、两阶段交付/奖励、玩家/NPC 预览及发布；玩家只读日志、实际生成、83/未完成与113/完成候选切换即时刷新。两者检查 390px 布局并保留截图。

完整门槛为 check/build、27 套离线回归、68 项 Chromium、准确提交的 Node 22/24 CI、真实资料副本逐文件对比，以及最终源码候选的 SHA-256/全新安装/HTTP/WS/版本/端口回收。每轮执行结果另存机器可读清单，失败记录保留。

真实模型人工验收：`not_requested`。尚未评测模型是否主动接取/推进、准确解释拒绝或把重写误当行动；叙事质量与真实可玩性未评测。合成测试不替代人工对照。
