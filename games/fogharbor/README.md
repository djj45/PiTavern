# 雾港最后一盏灯

**PiTavern 0.12.0 原创单人游戏 · 内容版本 1.1.0**

午夜，北灯熄灭，白鹭号迟迟未归。你拿着一份公所委托书来到雾港：是先让灯重新亮起，还是先问清谁见过昨夜的船？港城里的三个人都有自己的去处。把人找对，把证据留下，最后决定在灯亮时收束，还是继续查到能公开的答案。

这是一次由模型主持、服务端规则结算的港城调查。建议采用接管模式、开启工具及原生协议；双阶段可选，默认关闭。完整流程约 12–20 个有明确目标的行动回合，实际长度取决于模型和自由对话；尚未进行真实模型游玩评测。

## 直接开局（独立资料库）

在项目根目录安装依赖后运行，目标目录必须不存在，父目录必须存在：

```sh
npm ci
mkdir -p data
npm run game:prepare -- --output "$PWD/data/fogharbor-play"
PITAVERN_CONFIG="$PWD/data/fogharbor-play/config.json" npm start
```

命令准备角色卡、世界书、已发布模板及绑定模板的开场聊天。它拒绝覆盖任何已有目录，不读写你的常用配置、不复制 API Key，也不请求供应商。资料库路径为绝对路径；移动游戏目录后需相应修改 `config.json` 的 `stDataDir`。

进入设置，配置支持原生工具调用的模型（连接与发送会使用你的供应商额度），在侧栏打开《雾港最后一盏灯》。正常开局应显示：**第1天 00:00、潮声公所、30铜币、调查委托书**；林照、乔砚和燕迟都在场，任务日志有“备齐修灯材料”和“雾中的两份证据”。

建议第一句：**“查询当前世界和可用任务，接取两个公开任务，然后向燕迟出示委托书，询问昨夜航程。”**

内容1.1.0修正证据约束、行动可用性与材料任务命名，模板版本为2。已有聊天不自动替换卡/书或模板；复验请新建独立资料库，勿把旧分支记忆视为新规则的依据。

## 导入现有资料库

1. 「角色管理」导入 `character.json`。这是 V3 JSON 角色卡，内嵌 12 条公共世界书条目。
2. 「世界模板」导入 `template.json`，检查后点击「发布模板」。不要将它当成普通世界书导入。
3. 新建聊天，选择角色《雾港最后一盏灯》和同名已发布世界模板；使用默认开场白。已有聊天不会自动绑定新模板。
4. 使用接管模式、原生协议。工具默认开启；若面板提示“工具已关闭”，停止服务，在所用配置文件中将 `toolsEnabled` 设为 `true` 后重启，或使用独立开局命令。不要选择含其他故事设定的预设。

`worldbook.json` 是独立 ST 格式公共世界书，供编辑、移植或不带内嵌书的卡使用。**原卡已经带书，不要再启用独立同名书**，否则内容重复占用上下文。独立开局命令会保存它，但不加入启用列表。

## 玩家手册（不剧透）

- **调查**：出示委托书、核对证词、读值班簿。面板“已知线索”才是已确认内容；模型的猜测不等于事实。
- **修灯**：“备齐修灯材料”完成表示**材料已交付**；“灯塔已验证”另以已知线索为准。检查灯座 → 买备件 → 向乔砚交付 → 持回执在灯塔验收。聚光片售价18铜币，初始30足够完成必要购买。
- **赴约**：00:05乔砚到工坊、燕迟到栈桥、林照到灯塔；01:30乔砚来灯塔；02:00林照回公所。完整公开安排在卡内书。查询实际位置再行动。
- **时间**：仅明确等待推进时钟，移动和聊天不自动耗时。从00:05到01:30是等待85分钟。没有倒计时判负；错过可等待次日，日程每日重复。
- **任务**：先接取，再按当前目标推进。同一任务每轮最多推进一个阶段；完成交付时由任务结算扣物品、付奖励，不要再手动转移一次。
- **收束**：“灯火归航”对应完成引航任务并核验到港；还可以继续调查、公开材料，达成“岸上有证”。两者可先后达成，不会锁死聊天；标题是叙事里程碑，面板显示对应任务与事实。
- **存档**：切候选/重生成可能回到不同世界状态，先查任务、时钟与知识；双阶段“只重写正文”不会再结算。重要选择前可用聊天备份。

## 内容与规则边界

5个地点、3名NPC加玩家、4种物品、7条事实（其中6条受限）、6个揭示交互、4条任务、3份日程，共12条公共世界书条目。真相只在模板的受限事实中；卡片、公共世界书、初始正文均无答案。作者视图、模板文件、JSONL与备份包含秘密，玩游戏时不要阅读。

世界引擎提供状态与条件校验，但这不是对抗恶意玩家的锁箱：当前通用移动/转移/购买工具没有剧情所有权、凭据不可交易或路径封锁。卡片要求主持模型不挪用NPC任务凭据；强行调用通用工具可绕过故事流程。不开启自动战斗、惩罚、硬截止、互斥路线或离线NPC模拟。破晓只是文学意象，不是引擎倒计时。

可独立移植卡和书到支持相应格式的前端；完整交易、任务、知识与日程依赖 PiTavern 世界模板及工具，不能宣称导入其他前端后也有同等结算能力。

作者攻略与逐步工具流程见 [WALKTHROUGH.md](WALKTHROUGH.md)（含全部剧透）。测试见 `npm run verify:game`：合成工具链验证数据与执行，不替代真实模型叙事质量或人工可玩性评价。
